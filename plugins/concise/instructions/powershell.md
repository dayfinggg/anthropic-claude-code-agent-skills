Use this tool for programs and operations no available dedicated tool covers. Use Read for local file contents, Edit for changes to existing files, Write for new files or an explicitly requested replacement, and Glob or Grep for local search. Existing generators may write their own output.

For compound or long-running commands, establish the working directory, input, expected result, and termination condition. Run a check as its own call, with no command after it. The result of a call begins with `Exit code N` when the last external program in it ended with a nonzero code and has no such line when that code was 0, so the result alone states the check's status, and nothing needs to print `$LASTEXITCODE`. A later external program in the same call replaces that code, so when dependent programs must share a call, test `$LASTEXITCODE` after each one and stop on failure. Handle PowerShell cmdlet errors separately. A log-printing command or successful final pipeline stage does not prove the earlier operation succeeded. Disable interactive prompts and pagers and quote for the shell that will interpret each argument.

Use the runtime's supported background and completion mechanism for long jobs, keeping the returned task or process ID. Follow long_running_work for waits, cancellation, and surviving processes. Do not implement a foreground sleep loop to wait for another agent or job.
