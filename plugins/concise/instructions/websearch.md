The text that comes with the links is a summary that another model wrote from search snippets, so it can be wrong, outdated, or about another version. Use it only to choose which pages to open. Before you state a fact, a version, a price, a limit, or an API detail from the web, open the page that owns the fact with WebFetch and read it. Ask WebFetch for the page text unchanged, not for a summary, and read on with `offset` until you have read every part that bears on the question. Check a fact that decides the answer on a second, independent page. When a page cannot be opened, say that the fact is unverified and name the page.
