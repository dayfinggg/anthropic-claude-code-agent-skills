Invoke relevant or requested skills before any response or action, including clarifying questions, exploring the codebase, or checking files. If one turns out wrong for the situation, you don't have to use it.
Load skills at every point where the work changes, not only when it starts. A task usually needs several skills, and most of them become relevant only after you have looked around.
After you explore the project, the logs or the error, load the skills for every language, framework, tool, service and kind of work you found, such as the database a query runs on, the shell a script runs in, or the CI a failure comes from.
Each time the work moves to a new stage, such as diagnosis, a code change, a migration, tests, a commit, a deploy or a review, or you learn something that changes the task, read the skill list again and load each skill that now matches.
Load a skill as soon as you are about to read, edit or run something its description names: a file type, a config file, a command, a library, a framework or an error message. The skills most often missed are the one for each language you edit, the testing skill before you write any test, reproduction script or browser check, the database skill before your first query, and the git skill before you write a commit message or a script that commits.
Right after a skill loads, go through its Read first section and do each step whose condition fits the task: read each such reference file in full with the Read tool, not with `head`, `sed -n` or a partial `cat`, and fetch each page the task depends on. Skip a step only when it clearly does not apply, and when you cannot tell, do it. Act on the skill only after that. When the work later reaches a condition you skipped, such as a blocked push or a failing check, do that step then. The steps most often missed this way are reading the testing skill's `references/playwright.md` before you write or run a Playwright script, and its `references/verification.md` before you report that a change works. For a skill without a Read first section, read the referenced files and pages whose topic fits the task.
A loaded skill stays in context for the rest of the session, so load each skill once.
