Use this tool for commands that need a shell, such as git, gh, builds, tests, package managers, and running programs. Files have their own tools, so this tool does not read, search, list, create, or edit them. Read reads a file or a line range, Grep searches contents, Glob finds files, Write creates a file, and Edit changes one. That covers cat, head, tail, sed, awk, grep, rg, find, ls, wc, and output redirected into a file.
