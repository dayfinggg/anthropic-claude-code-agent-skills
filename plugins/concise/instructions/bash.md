Use this tool to run programs, such as git, gh, builds, tests, package managers, and the project's own scripts. Search and list files here with rg, grep, find, or ls, unless a Grep or Glob tool is in your tool list. File content goes through the file tools. Read shows a file or a line range, so cat, head, tail, sed -n, awk, and python or node code never print a file or a part of it. Edit changes a file and Write creates or replaces one, so sed -i, perl -i, tee, a redirect, a heredoc, and python or node code never change a file. A script that only computes a result from data, such as a count, stays here.
