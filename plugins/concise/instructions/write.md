Use this tool to create a local file required by the task. It can also replace a file you have read, and the user's rules narrow that use to a replacement the user explicitly requests. Change an existing file with Edit in every other case, also when the file is short or the change covers its only function, because an exact-match edit leaves the other lines untouched and shows the user the changed lines.
