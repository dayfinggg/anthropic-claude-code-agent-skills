This skill merges several sources. The MIT sources share the license text in `LICENSE`, which lists each copyright line. The Apache-2.0 sources keep their own license files in `playwright/LICENSE` and `chrome-devtools/LICENSE`.

`good-tests.md` is adapted from [`writing-good-tests.md`](https://github.com/obra/superpowers/blob/main/skills/test-driven-development/writing-good-tests.md) in obra/superpowers by Jesse Vincent, under MIT, at revision `22f0b463e7a5e579904dd6211a520321035526f7`. The link to `writing-skills` and the "your human partner" lines were removed. The quick reference table and the section on shipping tests with each change were removed too. The mirror assertion example was removed, because the `tdd` skill already covers tautological tests. Three warning signs come from `references/testing-patterns.md` in addyosmani/agent-skills.

The claim table in `SKILL.md` comes from [`verification-before-completion`](https://github.com/obra/superpowers/tree/main/skills/verification-before-completion) in obra/superpowers, under MIT. The rest of that skill was left out, because the `verification` block of the coding instructions covers it.

The test pyramid, the sizes, and the level guide in `SKILL.md` come from [`test-driven-development`](https://github.com/addyosmani/agent-skills/tree/main/skills/test-driven-development) by Addy Osmani, under MIT. The revision is `301b02b12bff98e4688e6984af6556802322bbde`. The "Beyonce Rule" was removed, because it asks for tests on every change, and the coding instructions limit new tests. The Supertest example in `cli-and-api.md` comes from `references/testing-patterns.md` in the same repository.

The security boundaries and the clean console rule in `chrome-devtools/chrome-devtools.md` come from [`browser-testing-with-devtools`](https://github.com/addyosmani/agent-skills/tree/main/skills/browser-testing-with-devtools) by Addy Osmani, under MIT. They were shortened to the rules, without the tables and diagrams.

`flaky-tests.md` takes the core rules of [`absolute-deflake`](https://github.com/maddhruv/absolute/tree/main/skills/absolute-deflake) by Absolute, under MIT, at revision `11cd3841183482e1753dec81763a8be6fdd97053`. The emoji, the command links, the shared engine reference, and the config setting were removed. The runner table was checked against the Jest, Vitest, pytest-repeat, and Playwright docs. Jest has no `--shuffle` flag, so the table uses `--randomize`. Vitest uses `--sequence.shuffle.files`, `--sequence.shuffle.tests`, and `--repeats`. A Playwright row was added.

The files in `playwright/` are adapted from the [`playwright-cli`](https://github.com/microsoft/playwright-cli/tree/main/skills/playwright-cli) skill by Microsoft Corporation, under Apache-2.0, at revision `4bc00fb7fa5b4329f2fb53ac4743a066c2c664e8`. `playwright-cli.md` is the original `SKILL.md`. `playwright-tests.md`, `request-mocking.md`, `test-generation.md`, and `tracing.md` are the reference files of the same names.

The changes remove code comments and headings and rewrite the prose to the plugin style. They drop the section on attaching media to pull requests and the links to reference files not shipped here. `test-generation.md` no longer asks for step comments or a spec header comment in tests. It asks before it bootstraps Playwright. The `resume`, `step-over`, and `pause-at` commands were added to `playwright-tests.md` from the CLI source in microsoft/playwright. All commands were checked against the current `playwright-cli` README and that source.

`chrome-devtools/chrome-devtools.md` is adapted from the [`chrome-devtools`](https://github.com/ChromeDevTools/chrome-devtools-mcp/tree/main/skills/chrome-devtools) skill by Google LLC, under Apache-2.0, at revision `0b37364dc0a88a804c6d73d3335e776adc7f33c4`. The changes rewrite the prose to the plugin style and remove a blockquote and bold text. The network, performance, and Lighthouse tools were added to the tool list from the current tool reference.

The sections on CLI testing and on API and contract testing in `cli-and-api.md` are original to this plugin.
