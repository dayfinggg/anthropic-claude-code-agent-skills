# Claude Code Agent Skills

[English](README.md) · [Українська](README.uk.md) · Русский

Снимок локальной настройки Claude Code автора на **2026-10-26**, включающий **13 инженерных навыков, стиль вывода nova и мод nova**, а также переносимые настройки.

Навыки охватывают изменения кода, тесты и диагностику дефектов, безопасность, серверную часть, базы данных, реализацию фронтенда, визуальный и UX-дизайн, архитектуру, планы реализации, сборку и эксплуатацию, сообщения коммитов, инструкции для ИИ-агентов и разбор проблем на работающих сайтах и сервисах. Каждое правило навыка говорит, когда оно действует, что делать и почему, и сопровождается примером.

Стиль вывода nova оставляет Claude без текста между вызовами инструментов и даёт один итоговый ответ на языке пользователя, который начинается с результата и обычно умещается в один короткий абзац. Шаги плана и вопросы к пользователю тоже пишутся на его языке, а описания инструментов и задания для других агентов остаются на английском.

Мод nova является плагином Claude Code с модулем хуков:

- Он заменяет разделы системного промпта о выполнении задач, инструментах, порядке работы, навыках и поиске своими файлами правил, где у каждого правила есть причина и пример.
- Он напоминает загрузить подходящий навык, если любой файл правится до загрузки навыка, и убрать комментарии, добавленные без запроса.
- Он присылает поправку после сообщения, где текст стоит перед вызовом инструмента, чтобы промежуточные фразы не повторялись.
- Он один раз возвращает Claude к задаче, если ход завершается, а временные файлы, записанные в этом ходе, ещё не удалены.
- Пока запущенные им агенты или фоновые команды ещё работают, он превращает запрос приложения на видимый ответ в указание продолжать ждать, чтобы не появлялось статусное сообщение. В Windows он держит инструмент Bash отложенным, чтобы локальные команды шли через PowerShell.
- Он добавляет к заданию каждого нового субагента блок рабочих правил о навыках, инструментах, проверке фактов, языке и удалении временных файлов, без ограничений длины из стиля вывода, чтобы отчёты агентов оставались подробными.
- Он убирает из описания инструмента Agent части, которые поощряют передавать побочные задачи агентам, и добавляет короткие напоминания после обновлений плана и долгих команд.

Это личная конфигурация, а не официальный продукт Anthropic. Учётные данные, состояние аккаунта, история чатов, проекты, сессии, плагины, синхронизированные навыки, кеши и локальные пути не публикуются.

> [!WARNING]
> Если в ваших настройках их нет, установщик добавляет `"permissions": { "defaultMode": "bypassPermissions" }` и `"skipDangerousModePermissionPrompt": true`. Тогда Claude Code выполняет любые вызовы инструментов без вопросов и не показывает окно подтверждения этого режима. [Документация режимов разрешений](https://code.claude.com/docs/en/permission-modes#skip-all-checks-with-bypasspermissions-mode) рекомендует этот режим только для изолированных сред, например контейнеров и виртуальных машин без доступа в интернет. Перед установкой проверьте [настройки](claude/settings.json) или сначала задайте собственный `permissions.defaultMode`, потому что установщик сохраняет существующие значения.

## Установка и замена старой версии

Скачайте и распакуйте [ZIP-архив](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/archive/refs/heads/main.zip) или клонируйте репозиторий:

```sh
git clone https://github.com/dayfinggg/anthropic-claude-code-agent-skills.git
cd anthropic-claude-code-agent-skills
```

Из распакованной или клонированной папки запустите установщик. Он использует включенные файлы без повторного скачивания.

### Windows

Требуется Windows PowerShell 5.1 или PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

### macOS и Linux

Требуется POSIX-совместимая оболочка, `python3` для объединения настроек и утилита SHA-256, например `sha256sum`, `shasum` или `openssl`.

```sh
sh scripts/install.sh
```

Перезапустите Claude Code после установки. Мод подключается через `CLAUDE_CODE_PLUGIN_DIRS`, для этого нужен Claude Code v2.1.280 или новее.

**По умолчанию выполняется полная замена.** Установщик сохраняет резервную копию и заменяет все навыки, кроме `skills/synced`, всех агентов, папку `output-styles` и папку `mods`, удаляя старый набор. Агенты больше не входят в набор, поэтому агенты из прошлой версии этой настройки удаляются после резервного копирования. Синхронизированные навыки, учётные данные, сессии, проекты, плагины и посторонние файлы сохраняются. Значения существующих настроек не заменяются и недостающие ключи добавляются, кроме `outputStyle`, который получает значение `nova`, и `env.CLAUDE_CODE_PLUGIN_DIRS`, где указывается установленная папка мода.

## Обновление

Чтобы скачать и установить актуальную версию с GitHub без обновления рабочей копии:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1
```

```sh
sh scripts/update.sh
```

Нужен интернет, для оболочки дополнительно нужны `curl` и `tar`. Обновление сохраняет выбранный режим установки. Для Git-клона можно вместо этого выполнить `git pull --ff-only` и повторно запустить установщик.

Файлы перенесены из локальной настройки байт в байт. В копии настроек нет `env.CLAUDE_CODE_PLUGIN_DIRS`, потому что установщик записывает это значение для каждой платформы, а папка `.claude-plugin/types` мода не включена, потому что [Claude Code создаёт эти определения типов](https://code.claude.com/docs/en/plugins/mods/create#get-the-types-for-your-build) для своей версии. Пустая папка `claude/agents` содержит только файл `.gitkeep`, чтобы установщик по-прежнему управлял этой папкой.

Claude Code хранит конфигурацию в `~/.claude` или в папке из переменной `CLAUDE_CONFIG_DIR`, как описано в [Environment variables](https://code.claude.com/docs/en/env-vars) и [Explore the .claude directory](https://code.claude.com/docs/en/claude-directory). Навыки загружаются из `skills/<skill-name>/SKILL.md` ([Extend Claude with skills](https://code.claude.com/docs/en/skills)), стили вывода из `output-styles` ([Output styles](https://code.claude.com/docs/en/output-styles)). `CLAUDE_CODE_PLUGIN_DIRS` загружает каждую указанную папку так же, как `--plugin-dir`, а абсолютные пути разделяются `;` в Windows и `:` в других системах ([Mods reference](https://code.claude.com/docs/en/plugins/mods/reference)).

## Проверка установщиков

Требуется Python 3.11 или новее:

```sh
python -m unittest discover -s tests -v
```

Тесты работают во временных папках и не затрагивают настоящую настройку Claude Code. Отсутствующие оболочки отмечаются как пропущенные проверки.

Сообщения об ошибках принимаются в [GitHub issues](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/issues). Инструкции и программы репозитория распространяются по лицензии [MIT](LICENSE).
