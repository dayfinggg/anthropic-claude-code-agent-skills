# Claude Code Agent Skills

[English](README.md) · [Українська](README.uk.md) · Русский

Переносимая копия настройки Claude Code автора для Claude Opus 5.5. Установщик ставит 33 инженерных навыка, одного субагента, стиль вывода Concise, мод oortveil и настройки, которые связывают их вместе.

Это личная конфигурация, а не официальная сборка Anthropic. В неё не входят учётные данные, состояние аккаунта, история чатов, проекты, сессии, плагины, навыки, синхронизированные с claude.ai, кэши и пути конкретной машины.

> [!WARNING]
> Переносимые настройки отключают запросы разрешений. Если в ваших настройках этих значений нет, установщик добавит `"permissions": { "defaultMode": "bypassPermissions" }`, `"skipDangerousModePermissionPrompt": true` и `env.CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS` со значением `1`. Тогда Claude Code выполняет любой вызов инструмента без вопроса, не просит подтверждения перед входом в этот режим и без вопроса запускает команды `rm`, которые сам считает опасными. [Документация по режимам разрешений](https://code.claude.com/docs/en/permission-modes#skip-all-checks-with-bypasspermissions-mode) советует этот режим только для изолированных сред, например контейнеров и виртуальных машин без доступа в интернет. Перед установкой просмотрите [настройки](claude/settings.json) или задайте свои значения заранее: установщик сохраняет уже заданные значения.

## Что меняет настройка

Стиль Concise заставляет Claude работать молча между вызовами инструментов. Итоговый ответ читается как короткая новость: сначала результат, потом несколько коротких абзацев простыми словами, без списков, заголовков, жирных меток, тире и точек с запятой. Всё, что читает пользователь, включая описания команд и пункты списка задач, пишется на языке пользователя. Файл стиля по имени заменяет встроенный стиль Concise.

Мод oortveil это плагин Claude Code с одним модулем хуков. Он подключается через `CLAUDE_CODE_PLUGIN_DIRS` и делает следующее:

- Откладывает десять редко нужных встроенных инструментов за поиск инструментов, поэтому их схемы не занимают контекст, пока модель их не запросит.
- Заменяет разделы системного промпта файлами правил из [`prompt/`](claude/mods/oortveil/prompt). Пустой файл убирает раздел, так мод убирает стандартное указание объявлять каждый шаг. Правила по коду описывают объём задачи, принципы DRY, KISS, YAGNI и SOLID, код без комментариев, безопасность, защиту от выдуманных API и пакетов и уточняющие вопросы.
- Добавляет короткие напоминания из [`reminders/`](claude/mods/oortveil/reminders) в тот момент, когда они нужны: перед каждым ответом, в описаниях инструментов оболочки, навыков и списка задач, а также перед каждым запросом, где модель проверяет каждый навык из списка.
- После каждого вызова инструмента напоминает модели язык из параметра `language`. Если пользователь пишет не латиницей, а итоговый ответ почти весь на латинице, мод возвращает ответ на переписывание. Однострочное сообщение на латинице, короткую английскую заметку, которую Claude Opus 5.5 иногда пишет перед вызовом инструмента, мод скрывает с экрана. У модели и в журнале сессии эта строка остаётся.
- Добавляет стиль, правила промпта и язык пользователя в задание каждого субагента, кроме форков, которые и так получают основной промпт.
- При сжатии контекста просит сохранить в сводке слова пользователя дословно, а сразу после сжатия напоминает модели правила и навыки, которые были в работе, чтобы она загрузила их снова.
- Сразу показывает в списке навыков навыки с полем `paths`, чтобы они работали и за пределами рабочей папки.

Переносимые настройки также задают `language`, оставляют встроенным навыкам и навыкам из claude.ai в списке только имя через `skillOverrides`, скрывают подпись в коммитах и pull request, блокируют коннекторы claude.ai Gmail, Google Calendar и Google Drive и выключают напоминание о долгой тишине, сводку после отсутствия, удалённый пересказ и автопамять.

## Установка или замена прежней настройки

Скачайте и распакуйте [ZIP-архив](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/archive/refs/heads/main.zip) или склонируйте репозиторий:

```sh
git clone https://github.com/dayfinggg/anthropic-claude-code-agent-skills.git
cd anthropic-claude-code-agent-skills
```

Запустите один из установщиков из распакованной или склонированной папки. Он берёт файлы из неё и ничего не скачивает.

### Windows

Нужен Windows PowerShell 5.1 или PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

### macOS и Linux

Нужны POSIX-оболочка, `python3` для объединения настроек и утилита SHA-256, например `sha256sum`, `shasum` или `openssl`.

```sh
sh scripts/install.sh
```

После установки перезапустите Claude Code. Мод требует Claude Code v2.1.280 или новее.

По умолчанию работает режим замены. Установщик сохраняет резервную копию и заменяет все навыки, кроме `skills/synced`, всех агентов, папку `output-styles` и папку `mods`. Синхронизированные навыки, учётные данные, сессии, проекты, плагины и посторонние файлы остаются на месте. Существующие значения настроек сохраняются, недостающие ключи добавляются. Исключения две: `outputStyle` становится `Concise`, а `env.CLAUDE_CODE_PLUGIN_DIRS` указывает на установленную папку мода. В переносимых настройках `language` равен `russian`, поэтому задайте свой язык до установки или поменяйте его после.

## Обновление

Чтобы скачать и установить последнюю версию с GitHub, не обновляя свою копию репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1
```

```sh
sh scripts/update.sh
```

Для обновления нужен доступ в интернет, а для обновления из оболочки ещё `curl` и `tar`. Используется режим последней установки. Если вы ведёте клон через Git, выполните `git pull --ff-only` и снова запустите установщик.

Большинство навыков и субагент основаны на [pstack](https://github.com/cursor/plugins/tree/main/pstack) Лорен Тан и [skills](https://github.com/mattpocock/skills) Мэтта Покока, оба под лицензией MIT. В [сторонних лицензиях](THIRD_PARTY_NOTICES.md) указано, какой навык откуда взят, и приведены исходные тексты лицензий.

В копии настроек нет `env.CLAUDE_CODE_PLUGIN_DIRS`: этот путь установщик записывает сам для каждой платформы. Папки `.claude-plugin/types` мода тоже нет, потому что [Claude Code создаёт эти описания типов](https://code.claude.com/docs/en/plugins/mods/create#get-the-types-for-your-build) для своей версии.

Claude Code хранит настройки в `~/.claude` или в папке из `CLAUDE_CONFIG_DIR`, как описано в [документации по переменным окружения](https://code.claude.com/docs/en/env-vars). Навыки загружаются из `skills/<имя-навыка>/SKILL.md` ([документация по навыкам](https://code.claude.com/docs/en/skills)), а стили вывода из `output-styles` ([документация по стилям вывода](https://code.claude.com/docs/en/output-styles)).

## Проверка установщиков

Нужен Python 3.11 или новее:

```sh
python -m unittest discover -s tests -v
```

Тесты работают во временных папках и не трогают вашу настройку Claude Code. Они запускают все доступные Windows PowerShell, PowerShell 7 и POSIX-оболочки, а недоступные отмечают как пропущенные.

Прежняя настройка со стилем и модом nova сохранена в [ветке `legacy`](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/tree/legacy).
