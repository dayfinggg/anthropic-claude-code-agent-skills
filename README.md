# vesper-sieve

What is not needed sleeps until it is called.

A Claude Code plugin that rewrites the instructions the model reads. It keeps rarely used tools out of the context until they are needed, replaces parts of the system prompt with its own rules for each Claude model, and adds seven skills that the model loads on its own.

## Install

```
claude plugin install vesper-sieve --marketplace dayfinggg/anthropic-claude-code-agent-skills
```
