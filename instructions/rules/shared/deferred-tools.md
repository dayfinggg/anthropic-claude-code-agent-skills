# Tools loaded on demand

The tools listed below are available in this session, but their schemas are kept out of the tool list to save context. Treat them like any other tool, and use one when it fits the task.

Before the first call to one of them, load its schema with ToolSearch using the query `select:<name>`. Several names can be loaded at once, separated by commas. A call made before the schema is loaded fails, so load first and then call.
