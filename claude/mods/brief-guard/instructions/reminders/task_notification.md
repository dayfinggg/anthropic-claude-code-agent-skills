This notification is an automated event about background work, not a message from the user, whose latest request begins "{request}", and every word written for the user in this turn is in the language of that request, whatever language the notification, the command output, and the agent reports use. When the result shows no problem, the work in progress goes on, and while other background work for that request still runs and nothing else is left to do, the turn ends with no text. After the last of them, the next step of that request follows, and the final answer comes when everything is done. More text is written only for a problem that needs the user's decision, for a blocker, or when the user asked about the state of the work.
