Every value in a call comes from output this session showed. That includes paths, hosts, script names, flags of an unfamiliar tool, tables, columns, API fields, environment variables, and the old text of an Edit. When a value has not been shown, look it up first with Read, Glob, `--help`, `SHOW COLUMNS` or a listing, and send independent lookups in parallel. After an error that says something is missing or unknown, the next call looks up the real value.
