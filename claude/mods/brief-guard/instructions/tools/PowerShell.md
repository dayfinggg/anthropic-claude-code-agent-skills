The purpose of the command goes in the description field. This runs programs such as tests, builds, git, package managers, ssh and curl. It is not for reading, searching or changing local files, because the file tools show each change. It is not for waiting, because background work reports by itself. After a run, its result goes in your thinking, and the next call follows with no text. Trim long output to the lines the step needs, such as failures or the last lines. For a service with a known CLI such as `gh`, use the CLI rather than its MCP server.
