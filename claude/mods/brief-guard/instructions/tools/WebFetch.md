A separate small model reads the page and only its answer to your prompt reaches you, so a reply that the page lacks something may only mean the prompt did not ask for it. Write the prompt as an extraction request that names the exact facts, values, versions, code, or sections you need and asks for them verbatim with their headings, fetch again with a narrower prompt when the reply is thin, and read a long page in parts with offset. When the work depends on exact text, such as a specification, a changelog entry, or an API reference, download it with curl into a new scratchpad folder and read it with Read, and for a page on code.claude.com or platform.claude.com download the same address with `.md` appended, because the page's markdown source comes whole while this tool reads at most 100,000 characters of the rendered page.
