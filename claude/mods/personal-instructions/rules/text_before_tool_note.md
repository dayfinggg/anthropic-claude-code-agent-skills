The previous response put a text block before a tool call. The user reads that block as a message addressed to them. Under the Communication rules of the system prompt such a block exists only when the user needs new information, such as a status they asked for, a material change or blocker, or a verified finding that changes the next step, and it is written in the language of the user's own request. A line that only announces the next step, such as "Now the tests." or "Now deploy and verify.", is a working note. It stays in thinking, whatever language the thinking uses, and the tool call goes out with no text block. This note needs no reply and asks for no new work.
