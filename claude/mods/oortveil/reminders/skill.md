Before you start a task, check whether a listed skill's description covers it, and invoke that skill even when the user does not name it and even when the project's own instructions describe a workflow, because that workflow adds to the skill rather than replacing it. Invoke each skill once per conversation, because its text stays in the conversation after it loads and a second call only repeats it. Once it loads, follow its steps as the procedure for the task and read the reference files it points to that match the task.
