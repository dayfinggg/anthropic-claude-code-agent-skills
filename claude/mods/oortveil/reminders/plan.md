Mark a step done as soon as its work is finished: send `{"advance": true}` in the same message as the first tool call of the next step, and mark the last step with the wrap-up. The user follows progress by this list, so a step left open after its work is done shows them the wrong state, and closing several steps at once at the end tells them nothing while the work runs. A subagent has no task list on screen, so a subagent never calls this tool.
