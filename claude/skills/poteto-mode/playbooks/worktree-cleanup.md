### Worktree and simulator cleanup

1. Snapshot and audit. Record free disk space (`df -h /` in Bash, `Get-PSDrive` in PowerShell), then run `<poteto-mode dir>/scripts/worktree-audit.sh [-b <pr-base-ref>] [repo-path]` through Bash. Without `-b` it checks `MERGED` against `origin/HEAD`, so pass `-b origin/<branch>` when PRs target another branch. It reads paths from `git worktree list`, never hand-typed, since a hand-typed path misses a worktree that lives elsewhere, such as one the Claude app created. It classifies each worktree by size, age, merge state, uncommitted work, and PR state, then suggests a bucket. Its newest-chat column scans Cursor transcripts and stays empty here, so find the sessions that touched a worktree by searching `~/.claude/projects/<slug>/*.jsonl` for its path in a background subagent instead.
2. The bucket is advice, not permission. The pinned and active sessions are the real artifact. Get that set from the user, or in the Claude desktop app from its session list (`mcp__ccd_session_mgmt__list_sessions`), and cross-check every candidate. The pinned set wins over the script's `safe`.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read the transcripts and report whether the session is pinned or ongoing and which worktrees it touches, because transcripts are bulk. A pinned session spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never show in the sidebar. Pick each subagent's model and effort from the Models table, per the Subagents section.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show the diff and get the user's explicit yes first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. A clean, merged, not-in-use worktree proceeds, because the cleanup request covers it. `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>`. If the dir survives on ignored build artifacts, delete it, then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm free space again and re-list.
6. Simulators and other reclaimers, on macOS. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, and package caches (pnpm, uv, brew, yarn) on any platform. Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** free space before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in use by which session, or uncommitted work).
