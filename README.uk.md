# Claude Code Agent Skills

[English](README.md) · Українська · [Русский](README.ru.md)

Переносна копія налаштування Claude Code автора для Claude Opus 5.5. Інсталятор ставить 33 інженерні навички, одного субагента, стиль виводу Concise, мод oortveil і налаштування, які поєднують їх.

Це особиста конфігурація, а не офіційна збірка Anthropic. До неї не входять облікові дані, стан облікового запису, історія чатів, проєкти, сесії, плагіни, навички, синхронізовані з claude.ai, кеші та шляхи конкретної машини.

> [!WARNING]
> Переносні налаштування вимикають запити дозволів. Якщо у ваших налаштуваннях цих значень немає, інсталятор додасть `"permissions": { "defaultMode": "bypassPermissions" }`, `"skipDangerousModePermissionPrompt": true` і `env.CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS` зі значенням `1`. Тоді Claude Code виконує будь-який виклик інструмента без запитання, не просить підтвердження перед входом у цей режим і без запитання запускає команди `rm`, які сам вважає небезпечними. [Документація про режими дозволів](https://code.claude.com/docs/en/permission-modes#skip-all-checks-with-bypasspermissions-mode) радить цей режим лише для ізольованих середовищ, наприклад контейнерів і віртуальних машин без доступу до інтернету. Перед встановленням перегляньте [налаштування](claude/settings.json) або задайте власні значення заздалегідь: інсталятор зберігає вже задані значення.

## Що змінює налаштування

Стиль Concise змушує Claude працювати мовчки між викликами інструментів. Підсумкова відповідь читається як коротка новина: спочатку результат, потім кілька коротких абзаців простими словами, без списків, заголовків, жирних міток, тире й крапок з комою. У звіті про готову роботу одне речення називає перевірку, яка її доводить, і те, чого ця перевірка не покриває. Усе, що читає користувач, зокрема описи команд і пункти списку завдань, пишеться мовою користувача. Файл стилю за назвою замінює вбудований стиль Concise.

Мод oortveil це плагін Claude Code з одним модулем хуків. Він підключається через `CLAUDE_CODE_PLUGIN_DIRS` і робить таке:

- Відкладає десять рідко потрібних вбудованих інструментів за пошук інструментів, тож їхні схеми не займають контекст, доки модель їх не запросить.
- Замінює розділи системного промпту файлами правил із [`prompt/`](claude/mods/oortveil/prompt). Порожній файл прибирає розділ, так мод прибирає стандартну вказівку оголошувати кожен крок. Правила щодо коду описують обсяг завдання, принципи DRY, KISS, YAGNI і SOLID, код без коментарів, безпеку, захист від вигаданих API і пакетів, уточнювальні питання, перевірку, яка доводить, що зміна працює, довгі завдання з планом у файлі та роботу із субагентами. Вони йдуть за порадами з [claude.dev](https://claude.dev/), блогу Anthropic для розробників, там, де ці поради збігаються з уподобаннями автора.
- Додає короткі нагадування з [`reminders/`](claude/mods/oortveil/reminders) саме тоді, коли вони потрібні: перед кожною відповіддю та в описах інструментів оболонки, навичок і списку завдань. Усі нагадування й правила лежать у файлах Markdown, тож текст змінюється без правки коду.
- Якщо користувач пише не латиницею, а підсумкова відповідь майже вся латиницею, мод один раз повертає відповідь на переписування мовою з параметра `language`.
- Прибирає коротку англійську нотатку, яку Claude Opus 5.5 іноді пише перед викликом інструмента. Однорядкове повідомлення латиницею, після якого йде виклик інструмента, випадає з потоку, тож його не видно ні в терміналі, ні в застосунку, ні в журналі сесії. Це працює й для субагентів.
- Якщо в попередній відповіді було тире, крапка з комою, список, заголовок або жирна мітка, мод разом із наступним запитом нагадує моделі про стиль. Відповідь через це ніколи не блокується.
- Якщо у збірці немає інструментів Glob і Grep, як у нативній збірці для Linux, правила кажуть моделі шукати через `grep` і `find` в оболонці.
- Додає правила промпту й мову користувача до завдання кожного субагента, крім форків, які й так отримують основний промпт.
- Під час стиснення контексту просить зберегти в підсумку слова користувача дослівно, а одразу після стиснення нагадує моделі правила й навички, які були в роботі, щоб вона завантажила їх знову.

Переносні налаштування також задають `language`, лишають вбудованим навичкам і навичкам із claude.ai у списку лише назву через `skillOverrides`, ховають підпис у комітах і pull request, блокують конектори claude.ai Gmail, Google Calendar і Google Drive та вимикають стиснення під час простою, нагадування про довгу тишу, підсумок після відсутності, віддалений переказ і автопам'ять.

## Встановлення або заміна попереднього налаштування

Завантажте й розпакуйте [ZIP-архів](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/archive/refs/heads/main.zip) або склонуйте репозиторій:

```sh
git clone https://github.com/dayfinggg/anthropic-claude-code-agent-skills.git
cd anthropic-claude-code-agent-skills
```

Запустіть один з інсталяторів із розпакованої або склонованої теки. Він бере файли з неї й нічого не завантажує.

### Windows

Потрібен Windows PowerShell 5.1 або PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

### macOS і Linux

Потрібні POSIX-оболонка, `python3` для об'єднання налаштувань і утиліта SHA-256, наприклад `sha256sum`, `shasum` або `openssl`.

```sh
sh scripts/install.sh
```

Після встановлення перезапустіть Claude Code. Мод потребує Claude Code v2.1.280 або новішої версії.

Типово працює режим заміни. Інсталятор зберігає резервну копію й замінює всі навички, крім `skills/synced`, усіх агентів, теку `output-styles` і теку `mods`. Синхронізовані навички, облікові дані, сесії, проєкти, плагіни й сторонні файли лишаються на місці. Наявні значення налаштувань зберігаються, відсутні ключі додаються. Винятків два: `outputStyle` стає `Concise`, а `env.CLAUDE_CODE_PLUGIN_DIRS` вказує на встановлену теку мода. У переносних налаштуваннях `language` дорівнює `russian`, тож задайте свою мову до встановлення або змініть її після.

## Оновлення

Щоб завантажити й встановити останню версію з GitHub, не оновлюючи свою копію репозиторію:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1
```

```sh
sh scripts/update.sh
```

Для оновлення потрібен доступ до інтернету, а для оновлення з оболонки ще `curl` і `tar`. Використовується режим останнього встановлення. Якщо ви ведете клон через Git, виконайте `git pull --ff-only` і знову запустіть інсталятор.

У копії налаштувань немає `env.CLAUDE_CODE_PLUGIN_DIRS`: цей шлях інсталятор записує сам для кожної платформи. Теки `.claude-plugin/types` мода теж немає, бо [Claude Code створює ці описи типів](https://code.claude.com/docs/en/plugins/mods/create#get-the-types-for-your-build) для своєї версії.

Claude Code зберігає налаштування в `~/.claude` або в теці з `CLAUDE_CONFIG_DIR`, як описано в [документації про змінні середовища](https://code.claude.com/docs/en/env-vars). Навички завантажуються з `skills/<назва-навички>/SKILL.md` ([документація про навички](https://code.claude.com/docs/en/skills)), а стилі виводу з `output-styles` ([документація про стилі виводу](https://code.claude.com/docs/en/output-styles)).

## Перевірка інсталяторів

Потрібен Python 3.11 або новіший:

```sh
python -m unittest discover -s tests -v
```

Тести працюють у тимчасових теках і не чіпають ваше налаштування Claude Code. Вони запускають усі доступні Windows PowerShell, PowerShell 7 і POSIX-оболонки, а недоступні позначають як пропущені.

Попереднє налаштування зі стилем і модом nova збережено в [гілці `legacy`](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/tree/legacy). Про проблеми пишіть у [GitHub issues](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/issues). Інструкції та скрипти репозиторію поширюються за [ліцензією MIT](LICENSE).
