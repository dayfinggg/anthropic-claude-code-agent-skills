# Claude Code Agent Skills

[English](README.md) · Українська · [Русский](README.ru.md)

Знімок локального налаштування Claude Code автора на **2026-10-26**, який містить **13 інженерних навичок, стиль виводу nova і мод nova**, а також переносимі налаштування.

Навички охоплюють зміни коду, тести й діагностику дефектів, безпеку, серверну частину, бази даних, реалізацію фронтенду, візуальний і UX-дизайн, архітектуру, плани реалізації, збирання й експлуатацію, повідомлення комітів, інструкції для ШІ-агентів і розбір проблем на робочих сайтах і сервісах. Кожне правило навички каже, коли воно діє, що робити й чому, і супроводжується прикладом.

Стиль виводу nova залишає Claude без тексту між викликами інструментів і дає одну підсумкову відповідь мовою користувача, яка починається з результату й зазвичай уміщується в один короткий абзац. Описи інструментів, кроки плану й завдання для інших агентів залишаються англійською.

Мод nova є плагіном Claude Code з модулем хуків:

- Він замінює розділи системного промпту про виконання завдань, інструменти, порядок роботи, навички й пошук своїми файлами правил, де кожне правило має причину й приклад.
- Він нагадує завантажити відповідну навичку, якщо будь-який файл змінюється до завантаження навички, і прибрати коментарі, додані без запиту.
- Він надсилає виправлення після повідомлення, де текст стоїть перед викликом інструмента, щоб проміжні фрази не повторювалися.
- Він один раз повертає Claude до завдання, якщо хід завершується, а тимчасові файли, записані в цьому ході, ще не видалені.
- Поки запущені ним агенти або фонові команди ще працюють, він перетворює запит застосунку на видиму відповідь на вказівку чекати далі, щоб не з'являлося статусне повідомлення. У Windows він тримає інструмент Bash відкладеним, щоб локальні команди йшли через PowerShell.
- Він додає до завдання кожного нового субагента блок робочих правил про навички, інструменти, перевірку фактів, мову й видалення тимчасових файлів, без обмежень довжини зі стилю виводу, щоб звіти агентів залишалися докладними.
- Він прибирає з опису інструмента Agent частини, які заохочують передавати побічні завдання агентам, і додає короткі нагадування після оновлень плану й довгих команд.

Це особиста конфігурація, а не офіційний продукт Anthropic. Облікові дані, стан облікового запису, історія чатів, проєкти, сесії, плагіни, синхронізовані навички, кеші та локальні шляхи не публікуються.

> [!WARNING]
> Якщо у ваших налаштуваннях їх немає, інсталятор додає `"permissions": { "defaultMode": "bypassPermissions" }` і `"skipDangerousModePermissionPrompt": true`. Тоді Claude Code виконує будь-які виклики інструментів без запитань і не показує вікно підтвердження цього режиму. [Документація режимів дозволів](https://code.claude.com/docs/en/permission-modes#skip-all-checks-with-bypasspermissions-mode) радить цей режим лише для ізольованих середовищ, наприклад контейнерів і віртуальних машин без доступу до інтернету. Перед встановленням перевірте [налаштування](claude/settings.json) або спершу задайте власний `permissions.defaultMode`, бо інсталятор зберігає наявні значення.

## Встановлення та заміна старої версії

Завантажте й розпакуйте [ZIP-архів](https://github.com/dayfinggg/anthropic-claude-code-agent-skills/archive/refs/heads/main.zip) або клонуйте репозиторій:

```sh
git clone https://github.com/dayfinggg/anthropic-claude-code-agent-skills.git
cd anthropic-claude-code-agent-skills
```

Із розпакованої або клонованої папки запустіть інсталятор. Він використовує включені файли без повторного завантаження.

### Windows

Потрібен Windows PowerShell 5.1 або PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

### macOS і Linux

Потрібна POSIX-сумісна оболонка, `python3` для об'єднання налаштувань і утиліта SHA-256, наприклад `sha256sum`, `shasum` або `openssl`.

```sh
sh scripts/install.sh
```

Перезапустіть Claude Code після встановлення. Мод підключається через `CLAUDE_CODE_PLUGIN_DIRS`, для цього потрібен Claude Code v2.1.280 або новіший.

**За замовчуванням виконується повна заміна.** Інсталятор створює резервну копію й замінює всі навички, крім `skills/synced`, усіх агентів, папку `output-styles` і папку `mods`, видаляючи старий набір. Агенти більше не входять до набору, тому агенти з попередньої версії цього налаштування видаляються після резервного копіювання. Синхронізовані навички, облікові дані, сесії, проєкти, плагіни й сторонні файли зберігаються. Наявні значення налаштувань не замінюються й відсутні ключі додаються, крім `outputStyle`, який отримує значення `nova`, і `env.CLAUDE_CODE_PLUGIN_DIRS`, де вказується встановлена папка мода.

## Оновлення

Щоб завантажити й встановити актуальну версію з GitHub без оновлення робочої копії:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1
```

```sh
sh scripts/update.sh
```

Потрібен інтернет, для оболонки додатково потрібні `curl` і `tar`. Оновлення зберігає вибраний режим встановлення. Для Git-клону можна натомість виконати `git pull --ff-only` і повторно запустити інсталятор.

Файли перенесені з локального налаштування байт у байт. У копії налаштувань немає `env.CLAUDE_CODE_PLUGIN_DIRS`, бо інсталятор записує це значення для кожної платформи, а папку `.claude-plugin/types` мода не включено, бо [Claude Code створює ці визначення типів](https://code.claude.com/docs/en/plugins/mods/create#get-the-types-for-your-build) для своєї версії. Порожня папка `claude/agents` містить лише файл `.gitkeep`, щоб інсталятор і далі керував цією папкою.

Claude Code зберігає конфігурацію в `~/.claude` або в папці зі змінної `CLAUDE_CONFIG_DIR`, як описано в [Environment variables](https://code.claude.com/docs/en/env-vars) і [Explore the .claude directory](https://code.claude.com/docs/en/claude-directory). Навички завантажуються зі `skills/<skill-name>/SKILL.md` ([Extend Claude with skills](https://code.claude.com/docs/en/skills)), стилі виводу з `output-styles` ([Output styles](https://code.claude.com/docs/en/output-styles)). `CLAUDE_CODE_PLUGIN_DIRS` завантажує кожну вказану папку так само, як `--plugin-dir`, а абсолютні шляхи розділяються `;` у Windows і `:` в інших системах ([Mods reference](https://code.claude.com/docs/en/plugins/mods/reference)).

## Перевірка інсталяторів

Потрібен Python 3.11 або новіший:

```sh
python -m unittest discover -s tests -v
```

Тести працюють у тимчасових папках і не зачіпають справжнє налаштування Claude Code. Відсутні оболонки позначаються як пропущені перевірки.
